## 📋 Предварительные требования

### 1. Настройка .env файла
Обязательно замените тестовые значения на реальные:

```bash
# Telegram Bot
BOT_TOKEN=ваш_реальный_токен_бота
ADMINS=ваш_id_админа

# Платежи
PAYMENT_CARD=номер_вашей_карты
PAYMENT_NAME=имя_владельца_карты

# Сервер WireGuard
SERVER_IP=публичный_ip_адрес_сервера
WG_PORT=51820

# База данных
DB_USER_PASSWORD=надежный_пароль
DATABASE=vpn_bot

# Опционально: группа для обязательной подписки
REQUIRED_GROUP_ID=id_группы_телеграм
```

### 2. Установка зависимостей
```bash
# Установка Python зависимостей
pip install -r requirements.txt

# Или через Docker
docker-compose up -d
```

### 3. Настройка WireGuard
```bash
# Установка WireGuard
apt update && apt install -y wireguard

# Генерация ключей
wg genkey | tee private.key | wg pubkey > public.key

# Настройка интерфейса wg0
# (используйте utils/vpn_cfg_work.py для автоматизации)
```

## ⚠️ Важные замечания

### Безопасность
1. Никогда не коммитьте `.env` файл с реальными данными
2. Используйте надежные пароли для БД
3. Ограничьте доступ к серверу по SSH ключам
4. Регулярно обновляйте систему и зависимости

### Производительность
1. Для >5000 пользователей рассмотрите переход на PostgreSQL с connection pooling
2. Настройте rate limiting (уже реализован в middlewares/Throttling.py)
3. Используйте Redis для кеширования при высокой нагрузке

### Масштабирование
- Горизонтальное: несколько инстансов бота с общей БД
- Вертикальное: увеличение ресурсов сервера
- WireGuard: можно настроить несколько интерфейсов для балансировки

## 🆘 Поддержка

При возникновении проблем:
1. Проверьте логи: `logs/*.log`
2. Убедитесь, что все зависимости установлены
3. Проверьте подключение к Telegram API
4. Убедитесь, что WireGuard сервис запущен

Контакты поддержки доступны в боте через команду `/support`.
